# Publishing Silver Fox

This repository is intended for source code, build scripts, and artwork that you have the right to share. Do not commit a compiled browser, a Mozilla download cache, local browser profiles, diagnostic logs, Apple signing credentials, or other private files.

Silver Fox is an independent experimental browser built using Mozilla Firefox technology. It is not affiliated with or endorsed by Mozilla. Keep the project license, upstream notices, and trademark disclosures intact.

Before making a public binary release, review redistribution and trademark requirements for the packaged Firefox engine and verify the rights to every bundled image. Test the new app on macOS with a separate profile and verify that none of the remaining Firefox UI or network services are misrepresented as Silver Fox services.

Automatic engine updates are disabled. A public binary release requires a security maintenance plan and an appropriate signing and notarization process. Source availability and notices may be required when distributing modified executables. This checklist is not a legal opinion.
